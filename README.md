# Emoji Piškvorky

[Play Emoji Piškvorky](https://joelmatejka.github.io/emoji-piskvorky/)

Piškvorky is a two-player game on a 15×15 board. Take turns placing pieces and get five in a row to win.

Each player can pick an emoji and a background color. The game saves your board, scores, and choices in your browser.

To play offline, download `index.html` and open it in a browser.
